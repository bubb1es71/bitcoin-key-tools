# Security Policy

## Reporting a Vulnerability

Please **do not** open a public issue for security vulnerabilities.

You can report a vulnerability through either of the following channels:

- **Email:** [bubb1es71@proton.me](mailto:bubb1es71@proton.me)
- **GitHub Security Advisory:** [Open a private advisory](https://github.com/bubb1es71/bitcoin-key-tools/security/advisories)

Please include as much detail as possible: a description of the vulnerability,
steps to reproduce, and any potential impact. You will receive a response as
soon as possible.
